# Border radius tokens

| Token | Value | Used for |
|---|---|---|
| `rounded` | 4 px | Small inline elements |
| `rounded-md` | 6 px | Form controls |
| `rounded-lg` | 8 px | Buttons, cards |
| `rounded-xl` | 12 px | Modals, large surfaces |
| `rounded-2xl` | 16 px | _verify if used_ |
| `rounded-full` | 9999 px | Pills, avatars |

To extract from Figma during inventory pass. Note any custom radius values used.
